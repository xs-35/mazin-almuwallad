# 📄 منصة بناء السيرة الذاتية الاحترافية الذكية (ATS Resume Builder Pro)

> **تطوير:** المبرمج ميزو / مازن ناصر المولد  
> منصة تفاعلية ومتكاملة لبناء، تحسين، وتصدير السير الذاتية المتوافقة مع أنظمة الفرز الآلي (ATS) باستخدام أحدث تقنيات الذكاء الاصطناعي وواجهات المستخدم الحديثة.

---

## 🌟 أبرز المميزات (Features)

### 🤖 مساعد الذكاء الاصطناعي الشامل (AI Assistant Hub)
* **توليد السيرة الذاتية بكبسة زر:** إنشاء وتحديث جميع أجزاء السيرة الذاتية (الملخص، الخبرات، المشاريع، المهارات، الشهادات) تلقائياً بناءً على المسمى الوظيفي.
* **إنشاء خطاب التغطية (Cover Letter Generator):** صياغة خطاب تغطية مخصص وموجه لمدراء التوظيف.
* **مطابقة الوصف الوظيفي (Job Description Tailoring):** تحليل الإعلان الوظيفي وضبط المهارات والكلمات المفتاحية لرفع نسبة القبول في الفرز.
* **الترجمة الفورية:** تحويل محتوى السيرة الذاتية بالكامل بين اللغة العربية والإنجليزية بنقرة واحدة.
* **صياغة وتحسين الخبرات:** إعادة صياغة مهام العمل باستخدام أفعال قوية ومخرجات ملموسة متوافقة مع ATS.
* **فحص وتقييم السيرة (Resume Audit):** تحليل درجة جودة السيرة الذاتية وتقديم نصائح تحسين مباشرة.
* **مُولّد أسئلة المقابلات:** التنبؤ بأبرز أسئلة المقابلات الشخصية المتوقعة بناءً على مسمّاك الوظيفي.

---

### 🎨 التخصيص والمرونة (Customization)
* **دعم ثنائي اللغة (Bilingual):** دعم كامل للغتين العربية والإنجليزية مع تبديل الاتجاه (RTL / LTR) تلقائياً.
* **نماذج وقوالب ATS متنوعة:** اختيار من بين عدة نماذج تصميمية مخصصة للعبور من أنظمة التوظيف الآلية.
* **تنسيق الألوان والخطوط:** التحكم في الألوان الرئيسية، أنواع الخطوط العربية والغربية، وحجم النصوص.
* **تصدير إلكتروني المباشر (PDF):** حفظ وتنزيل السيرة الذاتية بملف PDF عالي الجودة وجاهز للتقديم للشركات.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **HTML5 / CSS3:** الهيكلية الأساسية مع تصميم متجاوب لجميع الشاشات.
* **Tailwind CSS:** لتنسيق الواجهات وسهولة التخصيص visual design.
* **React.js (Standalone via Babel):** لإدارة حالة التطبيق والتفاعل السريع بدون الحاجة لإعدادات سيرفر معقدة.
* **Font Awesome Icons:** للأيقونات والتصميم البصري.
* **html2pdf.js:** لتحويل عناصر HTML وتنزيلها كملف PDF قياسي.
